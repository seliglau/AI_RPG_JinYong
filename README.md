🗡️ 金庸群俠傳 AI RPG
一個以金庸武俠世界為背景的文字 RPG 遊戲。只需上傳單一 Markdown 檔案，即可與任何 AI 開始沉浸式的江湖冒險！

🌟 遊戲特色
即插即玩：無需複雜安裝，下載 .md 檔案即可直接交給 AI 運行。
高度相容：支援市面上絕大多數主流 AI 平台。
零門檻、低消耗：不需使用昂貴的高階模型，免費且輕量即可順暢體驗。

🚀 如何開始遊玩
取得檔案：下載本專案的 RPG Markdown 檔案 (金庸RPG.md)。
https://github.com/seliglau/AI_RPG_JinYong/blob/main/README.md

上傳 AI：將檔案直接上傳到你選擇的 AI 聊天視窗中。
踏入江湖：輸入你的角色名字與出身編號，即可展開武俠人生！
